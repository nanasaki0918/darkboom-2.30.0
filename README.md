# 黑潮：深海觉醒 2.30.0｜Bug反馈

这里用于收集《黑潮：深海觉醒》**2.30.0玩家修复版**的Bug和处理反馈。

**本仓库只保存反馈说明和问题模板，不上传或分发游戏安装包、资源、存档、数据库及游戏修复工程。**

本人并非官方人员，本修复版不代表官方版本，仅供学习交流。

## 提交问题

- [安装、启动或更新问题](https://github.com/nanasaki0918/darkboom-2.30.0/issues/new?template=installation.yml)
- [游戏内Bug反馈](https://github.com/nanasaki0918/darkboom-2.30.0/issues/new?template=bug_report.yml)
- [查看已有反馈和处理进度](https://github.com/nanasaki0918/darkboom-2.30.0/issues)

请先搜索已有问题；遇到相同情况，可以在原问题下补充版本、环境和复现信息。一个Issue尽量描述一个问题。

反馈时写明：游戏显示的修复版本、使用的模拟器或设备、所在页面、操作步骤和实际现象。可以附截图或短视频，不需要懂代码、协议或逆向，也无需提供账号密码。

本仓库对应**2.30.0版**，与原1.1.0旧版的反馈区分开。游戏原版本同为2.30.0时，请尽量附上登录页显示的修复版本标识，便于判断是否来自同一修复包；找不到可以填写“不清楚”。

## 反馈范围

安装与启动、登录、主线和副本、招募与养成、大型活动和小游戏、邮件与奖励、后宅、商店、文字语言、音乐与语音等游戏体验问题。

当前推荐MuMu模拟器的Android 12环境，也可使用雷电模拟器安装；安装请预留10GB以上空间。其他环境的兼容问题也可反馈，请写明安卓系统版本。

## 附件范围

可附与问题有关的截图、短视频及脱敏的简短报错文字。请勿上传APK、OBB、游戏资源包、角色素材、存档、数据库、压缩游戏包或账号密码。

## 处理方式

反馈会按确认现象、复现、修复和验证的顺序整理。需要补充信息时，会在对应Issue中说明；修复后也会注明适用版本。关闭Issue时会说明处理结果或与已有问题的关联。

反馈区不承诺固定修复时间，也不将单个问题关闭视为整个系统已经完成。

详细反馈建议见[CONTRIBUTING.md](CONTRIBUTING.md)。
